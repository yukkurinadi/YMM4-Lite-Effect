# YMM4 軽量ピクセルソートプラグイン (PixelSortPlugin)

ゆっくりMovieMaker4 (YMM4) 用の高速映像エフェクトプラグイン**「軽量ピクセルソート」**です。
グリッチアート・サイバーパンク風演出・スタイリッシュなMV演出に最適です。

## 主な機能・特徴

1. **高速マルチスレッド処理**
`Parallel.For` と 64-bit 量子化ソートによる超高速・低遅延レンダリング。

2. **豊富なソート基準**
輝度 (Luminance)・色相 (Hue)・彩度 (Saturation)・RGB 各カラーチャンネルから選択可能。

3. **方向モード**
水平 (左→右 / 右→左)・垂直 (上→下 / 下→上)・カスタム角度の5種類。

4. **柔軟な閾値マスク**
下限・上限の2点で対象ピクセルの範囲を指定でき、閾値反転にも対応。

5. **有機的なグリッチ表現**
ランダム区間分割率とシード値で再現性のあるリアルなグリッチ感を付加。

6. **完全なキーフレームアニメーション対応**
角度・閾値・ランダム区間・適用率のすべてが YMM4 のキーフレームアニメーション・イージングに対応。

## 設定パラメータ一覧

| 項目名 | 説明 |
|---|---|
| **方向** | ソートの方向（垂直(上→下/下→上)、水平(左→右/右→左)、カスタム角度） |
| **角度** | カスタム角度選択時の方向角度（-360.0° 〜 360.0°） |
| **ソート基準** | 並び替える基準（輝度、色相、彩度、赤、緑、青） |
| **閾値(下限)** | ソート対象とする最小値（0% 〜 100% / 初期値: 30%） |
| **閾値(上限)** | ソート対象とする最大値（0% 〜 100% / 初期値: 90%） |
| **閾値反転** | ONにすると指定範囲外のピクセルをソート対象に反転 |
| **枠全体までソート** | ONにすると透明部分を含む枠全体までソート |
| **ランダム区間** | 区間をランダムに分割してグリッチ感を付加（0% 〜 100%） |
| **シード値** | ランダム区間分割の擬似乱数シード |
| **適用率** | 元画像とソート後画像のブレンド率（0% 〜 100%） |

## インストール方法

【手動】
このプラグインのzipまたはdllファイルを取得して、
`C:\YMM4\user\plugin\PixelSortPlugin\PixelSortPlugin.dll`
と配置してください。PixelSortPlugin フォルダは作成してください。
YMM4 を起動（または再起動）すると、エフェクト一覧に「**軽量ピクセルソート**」が追加されます。
