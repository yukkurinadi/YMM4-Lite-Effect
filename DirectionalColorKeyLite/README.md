# YMM4 軽量透過クロマキープラグイン (DirectionalColorKeyLite)

ゆっくりMovieMaker4 (YMM4) 用の高速映像エフェクトプラグイン**「軽量透過クロマキー」**です。
Vlahosアルゴリズムをベースにした方向性クロマキー処理で、
髪の毛・半透明部分も自然に残しながら背景色を高品質に除去します。

## 主な機能・特徴

1. **高精度半透明クロマキー**
Vlahosアルゴリズムによる方向性色分離で、グリーンバック・ブルーバック等の背景色を自然に除去。
髪の毛の細部や半透明な素材でもエッジが綺麗に残ります。

2. **任意の背景色指定**
緑・青だけでなく、任意の色をキーカラーとして設定可能。

3. **感度・閾値の細かな調整**
- 感度（抜き強度）: 背景色の判定範囲を広げる
- 閾値（境界バランス）: 背景と前景の境界基準を微調整

4. **エッジの柔らかさ調整**
半透明境界のフェード量を調整して自然な馴染みを演出。

5. **スピル除去**
髪の毛やオブジェクトのフチに残る背景色の被り（カラースピル）を除去。

6. **キーフレームアニメーション対応**
感度・閾値・エッジ柔らかさ・スピル除去のすべてが YMM4 のキーフレームアニメーションに対応。

------------------------------------------------------------------------
## 設定パラメータ一覧

| 項目名 | 説明 |
|---|---|
| **背景色** | キーイング（透過）する背景色（デフォルト: 緑） |
| **感度 (抜き強度)** | 背景色の判定感度（大きいほど広く透過） |
| **閾値 (境界バランス)** | 背景と前景の境界バランス基準（a2パラメーター） |
| **エッジ柔らかさ** | 半透明境界のフェード・足切り調整 |
| **スピル除去** | 髪の毛やフチに残る背景色の被りを除去する強度 |
| **前景出力** | OFFにするとアルファマスク（白黒）のみ確認できます |

## インストール方法

【手動】
このプラグインの dll ファイルを取得して、
`C:\YMM4\user\plugin\DirectionalColorKeyLite\DirectionalColorKeyLite.dll`
と配置してください。DirectionalColorKeyLite フォルダは作成してください。
YMM4 を起動（または再起動）すると、エフェクト一覧の「合成」「クロマキー」カテゴリーに「**軽量透過クロマキー**」が追加されます。
