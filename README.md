# YMM4 軽量エフェクト統合パック (Lite-Effect)

ゆっくりMovieMaker4 (YMM4) 用の3つの映像エフェクトプラグインを1つにまとめた統合パックです。

- ⚡ **軽量ピクセルソート** — グリッチ・サイバーパンク系演出
- 🎞️ **軽量透過クロマキー** — 高品質半透明背景除去
- 💡 **輻射光 (軽量版)** — 2次元大域照明・放射光

各プラグインは、それぞれのフォルダに配置して使用してください。

-----

## インスパイア元・元プラグイン

| プラグイン | 元プラグイン |
|---|---|
| 軽量透過クロマキー | [YMM4-DirectionalColorKey](https://github.com/routersys/YMM4-DirectionalColorKey) |
| 輻射光 (軽量版) | [YMM4-Radiance](https://github.com/routersys/YMM4-Radiance) |

## 収録プラグイン一覧

### 1. 軽量ピクセルソート (PixelSortPlugin)

グリッチアート・MV演出に最適な高速ピクセルソートエフェクト。

| 項目名 | 説明 |
|---|---|
| **方向** | ソートの方向（垂直(上→下/下→上)、水平(左→右/右→左)、カスタム角度） |
| **角度** | カスタム角度選択時の方向角度（-360.0° 〜 360.0°） |
| **ソート基準** | 並び替える基準（輝度、色相、彩度、赤、緑、青） |
| **閾値(下限)** | ソート対象とする最小値（0% 〜 100% / 初期値: 30%） |
| **閾値(上限)** | ソート対象とする最大値（0% 〜 100% / 初期値: 90%） |
| **閾値反転** | ONにすると指定範囲外のピクセルをソート対象に反転 |
| **枠全体までソート** | ONにすると透明部分を含む枠全体までソート |
| **ランダム区間** | 区間をランダムに分割してグリッチ感を付加（0% 〜 100%） |
| **シード値** | ランダム区間分割の擬似乱数シード |
| **適用率** | 元画像とソート後画像のブレンド率（0% 〜 100%） |

------------------------------------------------------------------------

### 2. 軽量透過クロマキー (DirectionalColorKeyLite)

Vlahosアルゴリズムベースの方向性クロマキー。髪の毛・半透明部分も自然に残します。
[YMM4-DirectionalColorKey](https://github.com/routersys/YMM4-DirectionalColorKey) を基にした軽量版です。

| 項目名 | 説明 |
|---|---|
| **背景色** | キーイング（透過）する背景色（デフォルト: 緑） |
| **感度 (抜き強度)** | 背景色の判定感度（大きいほど広く透過） |
| **閾値 (境界バランス)** | 背景と前景の境界バランス基準（a2パラメーター） |
| **エッジ柔らかさ** | 半透明境界のフェード・足切り調整 |
| **スピル除去** | 髪の毛やフチに残る背景色の被りを除去する強度 |
| **前景出力** | OFFにするとアルファマスク（白黒）のみ確認できます |

------------------------------------------------------------------------

### 3. 輻射光 (軽量版) (RadianceLite)

映像の明るい部分を光源とした2次元大域照明エフェクト。
[YMM4-Radiance](https://github.com/routersys/YMM4-Radiance) に着想を得た軽量実装です。

| 項目名 | 説明 |
|---|---|
| **強度** | 周囲へ届く光の明るさ（0% 〜 800% / 初期値: 100%） |
| **到達距離** | 光が届く最大距離（10px 〜 2000px / 初期値: 300px） |
| **拡散** | 面を照らす光と空気中で光る光の配合（100%で面のみ / 初期値: 60%） |
| **環境光** | 光が届かない場所の明るさ |
| **発光しきい値** | この明るさを超えた部分が光源になります（初期値: 70%） |
| **発光の強さ** | 光源が放つ光の量（0% 〜 1600% / 初期値: 150%） |
| **発光色** | 光に乗せる色（デフォルト: 白） |
| **遮蔽の強さ** | 不透明な部分が光を遮る度合い（初期値: 80%） |
