# YMM4 輻射光 (軽量版) プラグイン (RadianceLite)

ゆっくりMovieMaker4 (YMM4) 用の映像エフェクトプラグイン**「輻射光 (軽量版)」**です。
映像の明るい部分を光源として、周囲のオブジェクトを照らし空気中でも光を発する
2次元の大域照明 (Global Illumination) エフェクトを高速に実現します。

-----

## インスパイア元・元プラグイン

本プラグインは [YMM4-Radiance](https://github.com/routersys/YMM4-Radiance) をインスパイア元として制作した軽量版です。
オリジナルの Radiance Cascades 方式による高品質実装は上記リポジトリをご参照ください。

## 主な機能・特徴

1. **2次元大域照明 (GI)**
画像のしきい値を超えた明るい部分が自動的に光源となり、周囲の面を照らします。
Direct2D の多重解像度ガウスブラーによる高速な光の伝搬計算。

2. **本家 Radiance Cascades 準拠の光輝度カーブ**
YMM4-Radiance の Radiance Cascades アルゴリズムと同等の逆距離減衰カーブで、
芯のある強い輝きと外側へ広がるなだらかな大気光を再現。

3. **空気中での発光 (Air Glow)**
拡散パラメーターで「面を照らす光」と「空気中で光る光」の配合を調整可能。

4. **遮蔽対応**
不透明な部分で光が遮られ、自然な影と光の境界を表現。

5. **発光色のカスタマイズ**
光源の色を指定することで、炎のような暖色・青白い冷光など多様な演出が可能。

6. **キーフレームアニメーション対応**
強度・到達距離・拡散・環境光・発光しきい値・発光の強さ・遮蔽のすべてが
YMM4 のキーフレームアニメーション・イージングに対応。

## 設定パラメータ一覧

| 項目名 | 説明 |
|---|---|
| **強度** | 周囲へ届く光の明るさ（0% 〜 800% / 初期値: 100%） |
| **到達距離** | 光が届く最大距離（10px 〜 2000px / 初期値: 300px） |
| **拡散** | 面を照らす光と空気中で光る光の配合（100%で面のみ / 初期値: 60%） |
| **環境光** | 光が届かない場所の明るさ（下げると光の当たる場所だけ浮かび上がる） |
| **発光しきい値** | この明るさを超えた部分が光源になります（初期値: 70%） |
| **発光の強さ** | 光源が放つ光の量（0% 〜 1600% / 初期値: 150%） |
| **発光色** | 光に乗せる色（素材の色と掛け合わされます / デフォルト: 白） |
| **遮蔽の強さ** | 不透明な部分が光を遮る度合い（0で光がすべてを透過 / 初期値: 80%） |

## インストール方法

【手動】
このプラグインの dll ファイルを取得して、
`C:\YMM4\user\plugin\RadianceLite\RadianceLite.dll`
と配置してください。RadianceLite フォルダは作成してください。
YMM4 を起動（または再起動）すると、エフェクト一覧の「装飾」カテゴリーに「**輻射光 (軽量版)**」が追加されます。
